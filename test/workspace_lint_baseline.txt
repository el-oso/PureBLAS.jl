# The lint is name-level and conservative: it treats a claim as live to the end of the enclosing method and
# merges all methods of a name, so sequential re-claims, mutually exclusive if/ternary arms, and
# claim-once-then-thread-it-down all show up here. That is the intended trade — over-approximate, then
# justify in writing, exactly as req8_lint.jl does with its literals.
#
# HISTORY WORTH KEEPING: this file previously carried 16 pairs. Seven of them — every `X -> X` self-edge —
# were PHANTOMS produced by a scanner bug, not by the code: `_bodies` attributed lines to the preceding
# definition, so a docstring written above a function had its indented signature lines read as calls by
# whatever was defined before it. Where two methods of one name sat adjacent, that manufactured a self-call.
# They were baselined with confident-sounding reasons ("the pair exists only because all methods of a name
# are merged…") that described an artifact. The scanner now stops attributing at a `"""` at column 0.
# The lesson is about baselines generally: a justification written for a finding you did not verify is
# indistinguishable from one written for a finding that is real. Re-derive, do not re-read.
