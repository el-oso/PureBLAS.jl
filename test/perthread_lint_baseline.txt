# Reviewed `OncePerThread` owners. Each line is a claim that THIS buffer can never be live across a
# threaded call — see test/perthread_lint.jl for why that is the only thing that makes per-thread
# ownership safe, and what it cost when it was not true (getrf! 20/96 wrong, some NaN).
#
# Add a line here ONLY with one of the two arguments below, written out. If neither applies, the owner
# must be `Base.OncePerTask` instead (~13 ns more per lookup, which is nothing on a call large enough
# to have considered threading).
#
#   arena.jl  — `_ARENA` is the arena itself, and `gemm!`/`_symm!` refuse to thread while any scope is
#               live (`iszero(_arena().depth)`). That guard is what covers the 17 internal `gemm!` call
#               sites that sit inside an `@scope`, mechanically rather than by audit.
#
#   workspace.jl — the L3 pack pools are claimed INSIDE `_gemm_core!`, i.e. inside a chunk body, and a
#               chunk never yields (`test/yield_lint.jl` is the guard). They are per-chunk in practice,
#               so no migration can occur while one is held. This is the ONE case where the original
#               "a worker runs as a nested interval" argument actually holds.
#
#   blas2/level2.jl — the trsv reciprocal caches. trsv is Level-2 and never calls `gemm!`, so nothing on
#               that path can thread or yield.
#
#   blas3/level3.jl `_TRMM_BPF*` — the packed-trmm B buffer. VERIFIED: `_trmm_packed!` and
#               `_trmm_packedR!` contain ZERO public `gemm!` calls, so the buffer cannot be held across
#               a threaded join. This is the hot one — a per-task lookup here would be measurable — and
#               it is the one that needed no change.
#
#   blas3/level3.jl `_SYMM_SCR*` — the SERIAL symm path only. When `_symm!` threads it materializes into
#               the per-TASK twin `_symm_scr_mt` instead (see its definition). Kept per-thread because
#               the IdDict/Ref lookup was measured at ~130 ns dominating tiny symm, and the serial path
#               never yields, so it pays nothing and risks nothing.
