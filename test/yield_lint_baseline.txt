# Reviewed task-switch points in src/. A line here is allowed to yield because it is NOT inside a kernel
# and holds no `@scope`: per-thread scratch ownership (see src/arena.jl) only requires that no scope is
# live across a task switch.
#
#   lbt.jl   — `activate()`/`status` printing. User-facing IO, no scratch, never called from a kernel.
#   tune.jl  — the calibration driver: it sleeps while waiting for an idle machine and logs progress.
#              It runs measurements through public entries; each of those opens and closes its own scope
#              between the log lines, so no scope is ever live across one.
#
#   gemm.jl  — the M4 thread pool, and these four lines are the ONLY yields in a kernel file, so read
#              the reason carefully before adding a fifth.
#              * `Threads.@spawn _gemm_pool_worker` — pool construction, once per process, before any
#                gemm has borrowed anything.
#              * `lock(_MT_SETUP_LOCK) do` in `set_num_threads` — the same construction path, serialised
#                so two concurrent first calls cannot each push a pool. Never reached from `gemm!`.
#              * `wait(p.evs[i])` — an IDLE worker parking between jobs. It holds no scope: it has not
#                been given a chunk yet, and the chunk it ran last returned before this line.
#              * `yield()` in the driver's join — the driver has finished its OWN chunk (so its scope is
#                closed) and is waiting for the others. The yield is not optional: `@spawn` gives no
#                placement guarantee, two workers can share a thread, and a bare spin here deadlocked a
#                probe at 399% CPU.
#              The invariant still holds everywhere that matters: no `@scope` is live across any of
#              them, and a chunk BODY — the actual kernel — yields nowhere.
#
# Add a line here ONLY with such a reason. If a KERNEL ever needs to yield, do not baseline it: switch
# the owners to `Base.OncePerTask` (one line each, measured 14.7 ns vs 1.5 ns per lookup) instead.

# --- 2026-09-20, cooperative barriers. `_pool_barrier` yields, and it is reached from INSIDE a chunk
#              body — the one place the note above says never yields. The remedy that note prescribes
#              was applied rather than skipped: every buffer live across the barrier moved off the
#              per-thread owner.
#                * `gpackA`/`gpackB` → `_gpackws`, per TASK (workspace.jl). Cooperative A-packing
#                  meets the other workers while the packed B panel is live; a per-thread buffer
#                  could be taken by a task landing on that thread during the yield. The direct-B
#                  route never touches `gpackB`, so the measured sizes did not expose it; a
#                  transposed B would have.
#              The shared A-pack buffer the barrier exists to share is shared ON PURPOSE: its blocks
#              are written by disjoint workers and read only after the barrier.
#
#              WHY THE YIELD IS NOT OPTIONAL: a barrier has to block, and every blocking primitive
#              yields. A bare spin deadlocks when a worker has not been scheduled yet — the same
#              failure the driver's join entry above records at 399% CPU.
#
#              `test/perthread_lint.jl` is what actually adjudicates this: it reads the ownership
#              rather than the text, and it passes. Revert any owner above to per-thread and that
#              check fails even though this line stays baselined.
blas3/gemm.jl:GC.safepoint(); Base.yield()
